# 全構想に共通の決まり

各構想書の「2. 絶対条件」に、この内容を書き写す (構想書は 1 ファイルで完結させるため、参照ではなく書き写す)。
この文書を変えたときは、進行中の構想書にも反映する。

| No | 条件 | 内容 |
|---|---|---|
| C-1 | **外部通信の禁止** | 実行中は一切の外部通信をしない。クラウドのサービス、Web API、テレメトリ、自動更新、オンラインのデータ取得はすべて禁止 |
| C-2 | **ローカル完結** | 入力の読み込みから出力まで、すべて手元の PC の中で完結させる |
| C-3 | オフラインで導入できること | インターネットにつながらない PC へ導入する手順を README に書く (部品を持ち込んで入れる手順) |
| C-4 | 社内データを入れない | 本物の図面・書類はリポジトリに入れない。テストには自分で作ったデータを使う |
| C-5 | 言語 | 画面の表示、エラー、説明は日本語。専門用語には短い説明を添える |

## 外部通信の禁止の確かめ方 (Python の場合の例)

- 起動直後に、プロセス内の通信機能 (接続・名前解決) を、呼ばれたら例外を出す関数に置き換える。
- テストで、Python の監査フック (`sys.addaudithook`) を使い、実行中に通信が 0 件であること、起動した外部プログラムが想定どおりであることを確かめる。
