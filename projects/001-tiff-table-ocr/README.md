## 概要

図面の TIFF ファイルから、欄外左上に「構成表」と書かれた表を見つけ、OpenCV と Tesseract OCR で文字を読み取り、Excel に貼れる形 (TSV / CSV / xlsx / クリップボード) で出力する。外部通信は一切しない。
